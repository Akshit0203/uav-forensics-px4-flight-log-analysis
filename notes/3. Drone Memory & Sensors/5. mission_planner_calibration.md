# Mission Planner — Installation, Firmware & Calibration

---

# Part 1: Installing Mission Planner

## Download & Install

1. Download **Mission Planner** (latest version ~1.8.x).
2. Double-click the downloaded `.msi` file to run the installer.
3. Follow the setup instructions — the installer automatically installs USB and hardware drivers.

![](attachments/Pasted%20image%2020260706011326.png)

> If you receive a **DirectX installation error**, update your DirectX plug-in from the Windows Download Center.

> If Windows displays a **driver signature warning**, select **"Install this driver software anyway"** to proceed.

![](attachments/Pasted%20image%2020260706011439.png)

4. Once installed, a desktop shortcut is created.
5. Mission Planner **automatically checks for updates** when connected to the internet — always update when prompted.

---

# Part 2: Connect Autopilot to Computer

- Connect the flight controller to your laptop using a **micro-USB data cable**.
- **Always connect directly to a physical USB port** — not a USB hub.

> ⚠️ USB hubs frequently introduce communication errors and configuration issues when uploading firmware or downloading logs. **Avoid USB hubs.**

- Windows should automatically detect the board and load the appropriate **COM port drivers**.

# Part 3: Step-by-Step Configuration

## Mission Planner Interface

![](attachments/Pasted%20image%2020260706011708.png)

> The connection settings are in the **top-right corner**. Do NOT click "Connect" yet — firmware must be uploaded first.

---

## Step 1: Upload Firmware

1. Open Mission Planner → go to **Initial Setup** menu.
2. Click on the **quadcopter/multirotor icon** to download and install the latest firmware (e.g., ArduCopter v4.5.7 Quad).
3. Wait for the installation to complete — the screen turns **green** when firmware is successfully flashed.

> For legacy firmware: click **Install Firmware Legacy** → **Previous Version** → select desired version (e.g., AC 3.6.7 / AP 3.9.7).

---

## Step 2: Connect to Flight Controller

1. After firmware installation, click **Connect** in the top-right corner.
2. If the COM port is unknown, select **"Auto"**.
3. Make sure the board is connected to Mission Planner before proceeding.

![](attachments/Pasted%20image%2020260706011819.png)

---

## Step 3: Select Frame Type

1. Go to **Config** → **Mandatory Hardware** → **Frame Type**.
2. Select the appropriate configuration (e.g., **X-type quadcopter**).
3. Other options include hexacopter, octacopter (8 motors / coaxial quad).

![](attachments/Pasted%20image%2020260706011917.png)

---

## Step 4: Accelerometer Calibration

1. Go to **Mandatory Hardware** → **Accel Calibration**.
2. Click **"Calibrate Accel"** (the first option).
3. Place the drone in each physical orientation as prompted by the software.

> ⚠️ **Do NOT click the second calibration option.** The first (primary) accelerometer calibration is sufficient.

![](attachments/Pasted%20image%2020260706012017.png)

---

## Step 5: Compass Calibration

1. Go to **Mandatory Hardware** → **Compass**.
2. Click **"Live Calibration"** → Click **Yes**.
3. Physically **rotate the entire quadcopter along all axes** (3D circles) until the progress bar is full and Mission Planner confirms calibration is complete.

> **Best Practice:** Perform compass calibration with the flight controller **already mounted on the frame**. Calibrating sensors before mounting often causes physical mismatches and flight instability.

![](attachments/Pasted%20image%2020260706012050.png)

---

## Step 6: Radio / Transmitter Calibration

1. **Power on your transmitter** and ensure the receiver is bound and connected to the flight controller.
2. Go to **Mandatory Hardware** → **Radio Calibration**.
3. Click **"Calibrate Radio"**.
4. Move **both joysticks** to their physical extremes — up, down, left, right — so the software records maximum, minimum, and neutral channel values.
5. The on-screen bars will move to reflect calibration.
6. Click **"Done"** when finished.

![](attachments/Pasted%20image%2020260706012156.png)

---

## Step 7: Skip ESC/Servo Calibration

> **Skip this step** in Mission Planner for now. ESC calibration will be performed separately via the direct throttle method described in the assembly notes.

## Step 8: Configure Flight Modes

![](attachments/Pasted%20image%2020260706012305.png)

| Flight Mode | GPS Required? | Notes |
|---|---|---|
| **Stabilize** | ❌ | Basic manual mode — **recommended for beginners** |
| **Altitude Hold** | ❌ | Holds altitude automatically — **recommended** |
| **Loiter** | ✅ | GPS-assisted position hold — **recommended** |
| Auto | ✅ | GPS waypoint navigation |
| Circle | ✅ | Circles around a point |
| Drift | ✅ | Coordinated turn mode |
| Follow Me | ✅ | Follows the transmitter/GCS |
| Guided | ✅ | Point-and-click flight via GCS |
| Land | ❌ | Automatic landing |
| Sport | ❌ | Advanced acrobatic mode |

> ⚠️ **If you don't have GPS, only select modes that don't require GPS.** For first builds, stick to **Stabilize, Altitude Hold, and Loiter**.

---

## Step 9: Configure Failsafe Settings

![](attachments/Pasted%20image%2020260706012538.png)

Failsafe settings program safety limits for emergency scenarios:

| Failsafe Trigger | Action | Setting |
|---|---|---|
| **Low Battery** | Land or RTH | Set threshold at **10.5V** for a 3S LiPo (nominal 11.1V) |
| **Radio Signal Loss** | RTH or Land | Set to **Disabled** initially (or RTH once GPS is configured) |

> When battery voltage drops below 10.5V, the drone automatically returns to home. Similar failsafes can be configured for signal loss scenarios.

> **Optional Hardware** tab provides advanced features like GPS waypoint navigation.

---

## Step 10: Arming & Disarming

The flight controller shows **"Disarmed"** in the HUD window by default. Motors will not spin until explicitly armed.

### Arming (Mode 2)

1. Move the **left joystick down and to the RIGHT**.
2. **Hold for 3 seconds**.
3. Confirmation beep + HUD displays **"Armed"**.
4. You can now unplug USB — the system is active and ready to fly.

![](attachments/Pasted%20image%2020260706012658.png)

### Disarming (Mode 2)

1. Move the **left joystick down and to the LEFT**.
2. **Hold for 3 seconds**.
3. HUD displays **"Disarmed"** — flight controller is now inactive.

![](attachments/Pasted%20image%2020260706012756.png)

> After disarming, you can safely unplug the flight controller. **Calibration is complete.**

# Exam / Interview Points

### Installation
- Mission Planner = Windows-based **Ground Control Station (GCS)** software
- Always use a **data cable** (not charging cable) and a **direct USB port** (not a hub)
- Firmware screen turns **green** on successful flash

### Calibration Order (Mandatory)
1. **Frame Type** (X-quad, hex, octo)
2. **Accelerometer Calibration** (first option only)
3. **Compass Calibration** (live calibration — rotate drone in 3D)
4. **Radio Calibration** (move sticks to extremes)
5. **Skip** ESC/Servo calibration in Mission Planner

### Flight Modes
- No GPS: **Stabilize, Altitude Hold**
- With GPS: **Loiter, Auto, Circle, Follow Me, Guided**
- Beginners: **Stabilize + Altitude Hold + Loiter**

### Failsafe
- Low battery threshold for 3S: **10.5V** → triggers RTH or Land
- Radio signal loss → RTH

### Arming/Disarming (Mode 2)
- **Arm:** Left stick → **down-right**, hold 3 seconds
- **Disarm:** Left stick → **down-left**, hold 3 seconds
- "Disarmed" = motors will NOT spin (safety feature)
