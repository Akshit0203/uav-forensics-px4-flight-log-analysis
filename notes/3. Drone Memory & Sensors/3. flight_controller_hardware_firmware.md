# Flight Controller — Hardware, Firmware & UAV Operating Systems

> The flight controller is the **heart and brain** of the drone — it serves as the aircraft's CPU and operating system.

---

# Flight Controller Hardware

## Internal Architecture

| Component | Full Form | Role |
|---|---|---|
| **FMU** | Flight Management Unit | Core flight processing, sensor fusion, stabilization |
| **IOMCU** | Input/Output Microcontroller Unit | Handles PWM outputs, failsafe, I/O management |

## APM vs Pixhawk

| | APM | Pixhawk |
|---|---|---|
| **Processor** | 8-bit Arduino ATmega2560 | **32-bit ARM Cortex** |
| **Status** | Legacy, unsupported ~7 years | Current standard |

## Pixhawk Version Differences (2.4.6 vs 2.4.8)

| Feature | Pixhawk 2.4.6 | Pixhawk 2.4.8 |
|---|---|---|
| Barometer | **MS5611** (more accurate) | MS5607 (less accurate) |
| RAM | 256 KB | 256 KB |

> On retailer sites (e.g., Robu.in), "good quality" versions typically feature the more accurate MS5611 barometer.

---

## Evolution of Pixhawk Hardware

| Version | Designed By | Notes |
|---|---|---|
| **Pixhawk 1** | 3D Robotics + PX4 team | Based on open-source **FMUv2** schematics |
| **Pixhawk 2** (FMUv3) | Philip Rowse (3DR) | Built by 3DR in the Solo |
| **Pixhawk 2.1 "The Cube"** | Philip Rowse / Hex Technology | First "Cube" autopilot |
| **Cube Yellow & Orange** | ProfiCNC / HEX | Enhanced Cube variants |
| **Pixracer** | Philip Kocmoud / mRo | Compact racing FC |
| **Pixhawk 3** | Drotek | — |
| **Pixhawk 4** | Holybro | — |
| **V5** | CUAV | FMUv5-based design |
| **HK32Pilot** | Hobby King | Basically a Pixhawk 1 clone |

> ⚠️ **The Pixhawk naming is NOT open** — only the hardware schematics are open-source. Various manufacturers produce boards with minor proprietary modifications. **RadioLink "Pixhawk" is not even a binary-compatible clone.**

# Firmware (Software Stacks)

The three most popular flight controller firmware options:

| Firmware | Strengths | Complexity | Best For |
|---|---|---|---|
| **ArduPilot** | Autonomous flight, GPS navigation, VTOL, airplane configs | Complex (most setup knowledge needed) | Commercial, research, autonomous missions |
| **Betaflight** | Agile flight, optimized PID loops | Beginner-friendly | FPV racing |
| **INAV** | GPS stabilization, steady hover, airplane configs | Beginner-friendly | Cinematography, aerial mapping, GPS waypoints |

### Feature Comparison

| Feature | ArduPilot | Betaflight | INAV |
|---|---|---|---|
| Cinematography / Stable Hovering | ✅ | ❌ | ✅ |
| Autonomous Flight & Navigation | ✅ (leader) | ❌ | ✅ (close second) |
| Airplane Configurations | ✅ | ❌ | ✅ |
| VTOL Support | ✅ (full support, leader) | ❌ | Partial |
| FPV Racing | Partial | ✅ (optimized) | ❌ |
| User-friendliness | Complex | Easy | Easy |

> **ArduPilot is the go-to choice** for drone builds in this course due to its robust autonomous capabilities.

### Legacy Software (Historical)

- APM Mission Planner
- Mega Pirate Mission Planner
- Multi Viewer
- MultiWii GUI

# UAV CPUs & Operating Systems

## Open-Source Flight Controllers

| Project | Hardware |
|---|---|
| **ArduPilot** | APM, Pixhawk |
| **OpenPilot** | Open-source boards |
| **MultiWii** | Arduino-based |
| **KK Multicopter** | KK boards |

> All open-source — publicly available PCB schematics; anyone can manufacture them.

## Commercial (Proprietary) Flight Controllers

| System | Manufacturer |
|---|---|
| **Naza** | DJI |
| **Wookong** | DJI |
| **Parrot AR.Drone FC** | Parrot |
| **Dualsky** (FC450 etc.) | Dualsky |

### Operating System

> **Linux** is the predominant OS for onboard UAV companion computers and high-end drone systems.

---

## Arming the System

Once the flight controller is installed and secured, press the **safety reset switch** on the flight controller to **arm the system** and allow throttle input.

# Exam / Interview Points

### Hardware
- **FMU** = Flight Management Unit | **IOMCU** = I/O Microcontroller Unit
- APM = 8-bit Arduino ATmega2560 | Pixhawk = **32-bit ARM Cortex**
- Pixhawk 2.4.6 (MS5611, accurate) vs 2.4.8 (MS5607, less accurate)
- Pixhawk naming is **not open** — only schematics are open-source
- RadioLink "Pixhawk" = **not binary compatible**
- Evolution: Pixhawk 1 → 2 (FMUv3) → 2.1 "The Cube" → 3 → 4 → V5

### Firmware
- **ArduPilot** = autonomous/commercial standard (complex setup)
- **Betaflight** = FPV racing (beginner-friendly)
- **INAV** = cinematography/GPS navigation (beginner-friendly)
- ArduPilot = leader for VTOL and autonomous missions
- Current ArduCopter version: **3.6.5**

### OS & Architecture
- Open-source: ArduPilot, OpenPilot, MultiWii, KK Multicopter
- Commercial: DJI Naza/Wookong, Parrot, Dualsky, Zero UAV
- **Linux** = predominant UAV onboard OS
- Press **safety switch** to arm the system before throttle input
