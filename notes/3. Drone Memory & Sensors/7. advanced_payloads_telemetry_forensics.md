# 1. Advanced Drone Payloads

![550](attachments/Pasted%20image%2020260706012929.png)

> A fully assembled, high-end quadcopter may include: flotation mechanism, optical flow sensor, real-time FPV camera, laser rangefinder, GPS module, and a stabilized camera gimbal.

## Specialized Payload Sensors

| Sensor | Function | Use Case |
|---|---|---|
| **Multispectral / Hyperspectral** | Captures specific light bands invisible to the human eye | Agriculture — crop health monitoring |
| **Thermal Camera** | Detects heat signatures | Search & rescue, firefighting, building inspections |
| **Airspeed Sensor (Pitot Tube)** | Measures wind speed and dynamic pressure relative to the drone | Fixed-wing drones, windy conditions |

## Obstacle Detection & Positioning Sensors

| Sensor | How It Works | Use Case |
|---|---|---|
| **Optical Flow** | Downward-facing camera analyzes ground movement by detecting visual changes | Stable **indoor hovering** when GPS is unavailable |
| **Ultrasonic (Sonar)** | Emits sound waves, measures echo return time to calculate distance | Smooth, safe landings |
| **LiDAR** | Rapid laser pulses map terrain and detect obstacles in 3D with extreme precision | Automated obstacle avoidance |
| **Vision Sensors** | Optical cameras feed visual data into intelligent obstacle-avoidance algorithms | Real-time environmental awareness |

> **Forensic Importance:** Identifying which sensors are present on a recovered drone is a key part of drone forensics — it reveals the drone's capabilities and intended mission.

## GPS / GNSS

GPS triangulates satellite signals to track the drone's **precise global position**, enabling RTH and waypoint navigation.

| Model | Price | Notes |
|---|---|---|
| **U-blox 7M** | ~₹3,000 | Basic GPS module |
| **Neo-M8N** | ~₹6,000–7,000 | Popular mid-range; may include physical reset button, buzzer, LED |
| **M9N** | ~₹10,000+ | Newer, higher precision |
| **M10N** | ~₹10,000+ | Latest generation |

> High-precision GPS is a **must** for professional drone operations and mapping.

# 2. Drone Memory & File Systems

## File Systems Overview

| File System | Typically Found On |
|---|---|
| **NTFS** | Windows OS, some drone internal storage |
| **APFS** | macOS / Apple devices |
| **ext4 / other Linux FS** | Linux-based drones, companion computers |
| **FAT32** | SD cards, USB drives, removable media |
| **UBIFS** | Unsorted Block Image File System (embedded flash) |
| **F2FS** | Flash-Friendly File System (optimized for NAND flash) |

> **Forensic Challenge:** A single investigation may involve an SD card (FAT32) from a drone running NTFS, connected to a Mac (APFS) — each file system requires different forensic tools and analysis approaches.

### Forensic Tools

- **USBDetective** — open-source USB forensic analysis
- **FSAnalysis** by Sleuth Kit (makers of **Autopsy**) — file system analysis
- SD cards and USB drives have their **own independent field of forensic analysis**
- Some devices can be enabled with **BitLocker** encryption — adds another forensic layer

## SD Card on a Flight Controller — What It Stores

### 1. Blackbox Logging (Diagnostics & Tuning)

The **most common use** in FPV drones.

| Data Recorded | Purpose |
|---|---|
| Gyroscope data | Detect vibrations, resonance |
| Accelerometer readings | Stability analysis |
| Battery voltage & temperature | Power diagnostics |
| Motor outputs | Motor desync detection |
| Receiver inputs | Input correlation |

- If you experience motor desync, mid-air twitching, or **flyaways**, pull the SD card and review logs in **Betaflight Blackbox Explorer**.
- Logs help spot resonant vibrations → adjust **PID and filter settings** for smoother flight.

### 2. Autonomous Missions (Waypoints)

- For fixed-wing UAVs and advanced multicopters running **ArduPilot** or **PX4**, an SD card is often **required** for autonomous tasks.
- **Mission Storage:** Stores massive coordinate files for long-range autonomous surveys.
- **Firmware/Bootloader:** Some flight controllers allow firmware or bootloader updates directly via the SD card.

### 3. Mass Storage & Quick Transfers

- Flight controllers with onboard flash memory can be **slow** to download log files.
- Many **F4, F7, and H7** boards support **Mass Storage Device mode** on the SD card.
- When plugged into a PC, the FC mounts the SD card — **drag and drop** log files at high speed.

# 3. FPV (First-Person View) Drones

**FPV** = a piloting method where you wear specialized video goggles or use a monitor connected to an onboard camera, giving the perspective of sitting inside the aircraft.

## Types of FPV Drones

| Type | Description |
|---|---|
| **Cinewhoops** | Smaller, propeller-guarded drones for indoor / close-proximity cinematic shots |
| **Freestyle / Racing** | Acrobatic drones with durable carbon-fiber frames, manual unassisted flight |
| **Long-Range** | Larger rigs (e.g., 7-inch props) for cinematic cruising and endurance |

## Core FPV Gear

| Component | Options |
|---|---|
| **The Drone** | Pre-built RTF kits (DJI Avata 2, EMAX Tinyhawk) or DIY builds with Betaflight |
| **The Goggles** | Analog: Eachine EV800D (budget) → Digital HD: DJI or Walksnail (premium) |
| **The Radio Controller** | Protocols: **ExpressLRS (ELRS)** or DJI proprietary controller |

## Flight Modes: Angle vs Acro

| Mode | Behavior |
|---|---|
| **Angle Mode** | Self-levels when sticks released (like GPS drones) — beginner-friendly |
| **Acro (Manual) Mode** | No artificial flight boundaries — enables dives, flips, power loops. **Steep learning curve.** |

> New FPV pilots heavily rely on **simulators** (Liftoff, Velocidrone) before flying real aircraft in Acro mode.

# 4. Telemetry

**Drone flight telemetry** = the automated, real-time exchange of navigation, system, and sensor data between the UAV and a Ground Control Station (GCS).

## Telemetry Data Categories

| Category | Metrics |
|---|---|
| **Position & Location** | GPS coordinates (Lat, Long, Alt) |
| **Attitude & Orientation** | Pitch, roll, yaw angles |
| **Dynamics** | Airspeed, ground speed, heading |
| **Power Metrics** | Battery voltage, current draw, temperature, estimated flight time remaining |
| **System Health** | Motor RPM, vibration levels, autopilot state machine flags |
| **Payload Data** | Gimbal angles, camera ISO/shutter speed, LiDAR scan status |

## How Telemetry Works

A continuous **two-way communication loop**: onboard sensors collect data → flight controller processes it → onboard transmitter sends it to the operator's device.

| Communication Method | Use Case |
|---|---|
| **RF** (433 MHz, 915 MHz, 2.4 GHz) | Custom-built drones, long-range FPV |
| **Wi-Fi** | Consumer drones (DJI, etc.) |
| **Cellular (LTE/4G)** | Beyond Visual Line of Sight (BVLOS) — theoretically unlimited range |

## Software & Analysis

| Use | Tools |
|---|---|
| **Real-Time Monitoring** | Mission Planner, QGroundControl — HUD + moving map overlays |
| **Post-Flight Analysis** | Flight logs (structured, timestamped telemetry records) — forensic reconstruction, tampering detection, anomaly analysis |
| **Video Overlay** | Overlay telemetry gauges (speed, altitude, G-forces) onto recorded HD flight footage |

# Exam / Interview Points

### Payloads
- **Multispectral** = invisible light bands → agriculture
- **Thermal** = heat signatures → SAR, firefighting
- **Pitot tube** = airspeed → fixed-wing / windy conditions
- **Optical flow** = indoor hovering without GPS
- **LiDAR** = 3D terrain mapping + obstacle avoidance
- GPS models: 7M → M8N → M9N → M10N (price increases with precision)

### Memory & Forensics
- **Blackbox logs** = gyro, accel, battery, motor outputs, receiver inputs
- **Betaflight Blackbox Explorer** = tool for analyzing FPV flight logs
- SD card stores: blackbox logs, waypoint missions, firmware/bootloader
- **Mass Storage mode** on F4/F7/H7 = drag-and-drop log extraction
- Forensic challenge: single case may span FAT32 + NTFS + APFS
- Tools: **USBDetective**, **Autopsy / Sleuth Kit (FSAnalysis)**
- BitLocker encryption may be present on removable media

### FPV
- Types: Cinewhoop, Freestyle/Racing, Long-Range
- Gear: Drone + Goggles + Radio Controller
- **Acro mode** = no self-leveling → simulators (Liftoff, Velocidrone) before real flight
- Protocols: **ELRS**, DJI proprietary

### Telemetry
- Real-time two-way data: position, attitude, dynamics, power, system health, payload
- Communication: RF / Wi-Fi / Cellular (LTE)
- **Flight logs** = structured timestamped records → **forensic reconstruction**
- Post-flight analysis detects **tampering and anomalies**

### Geolocation Data Storage
- Geolocation data is saved/cached differently depending on drone quality
- **RTK** (Real-Time Kinematic) drones use RF and RFID tagging for precise spatial positioning
- Military / agricultural survey drones use **live GPS + GIS databases** for real-time positioning
- High-quality drones with gimbal cameras can **live-stream video** and offload data to ground devices (phones) in real-time

### 4 Primary Forensic Data Locations
1. **Flight Controller memory** (onboard flash)
2. **SD card** (blackbox logs, missions, firmware)
3. **USB drives** (data transfers, firmware updates)
4. **GPS module memory** (cached coordinates, satellite data)

> Live feeds and user device endpoints are crucial for **reverse-engineering preconfigured flight paths** and determining the drone's origin.
