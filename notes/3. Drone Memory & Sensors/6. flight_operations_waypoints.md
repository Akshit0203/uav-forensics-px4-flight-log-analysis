# Waypoint Programming in Mission Planner

Waypoint programming involves pre-programming a sequence of **GPS coordinates** that an autonomous vehicle (drone, rover, or plane) will navigate. It is the backbone of automated tasks such as:

- **Photogrammetry mapping**
- **Search and rescue**
- **Agricultural spraying**

---

## Core Steps to Program Waypoints

### Step 1: Connect & Set Home

- Connect your drone or open Mission Planner.
- Zoom in on your flying area.
- **Right-click** the map where your vehicle will take off → select **"Set Home Here"**.

### Step 2: Define Defaults

- On the right-side command panel, ensure the default altitude is set to **Rel (Relative)** to the home point.
- Input a safe altitude (e.g., **10–30 meters** depending on environment).

### Step 3: Place Waypoints

| Method | How |
|---|---|
| **Manually** | Click on the map to drop individual waypoints. |
| **Automatically** | Right-click map → **Auto WP** → **Survey (Grid)** for automated mapping, or **Create Spline Circle** for curved paths. |

### Step 4: Edit Commands & Actions

In the grid table at the bottom, change the behavior for specific waypoints:

| Command | Action |
|---|---|
| **TAKEOFF** | Drone lifts off to specified altitude |
| **LAND** | Drone lands at waypoint |
| **LOITER** | Hover at waypoint for a set duration |
| **DO_SET_ROI** | Point camera at a Region of Interest |

### Step 5: Write to Vehicle

- Once the mission looks correct on the 2D/3D map, click **"Write WPs"** (right side panel) to upload the mission to the flight controller.

## Essential Tips

| Tip | Details |
|---|---|
| **Prefetch Maps** | For areas without internet: click **Prefetch** (top right) → hold **Alt** → draw a box to save satellite imagery offline. |
| **Avoid Obstacles** | Use **Spline Waypoints** (for copters) to create smooth, curved arcs instead of sharp, jerky turns. |
| **Verify Missions** | Always review routes for safe altitude and obstacle clearances before uploading. |

# Setting Up Servo / Auxiliary Switches (Tx/Rx Channel)

Configure auxiliary channels on your transmitter to control servos (e.g., payload drop, gimbal) via Mission Planner.

### Transmitter Setup

1. On the transmitter, go to **Aux Channel** settings.
2. Shift left for **Channel 6**, select the input type:

| Code | Input Type |
|---|---|
| **Nul** | None |
| **VRx** | Variable knob (VrA or VrB) |
| **SWx** | Switch (A, B, C, D) |
| **Key** | Key button (1 or 2) |

3. Select the desired input (e.g., **VrA** or **VrB** for variable knob control).

### Mission Planner Setup

4. In Mission Planner, click **Connect**.
5. Go to **Setup** → **Mandatory Hardware** → **Servo Output**.
6. On **Channel 6** (or the relevant channel), select **RCIN 6** or **RCIN 7** to pass through the transmitter input to the servo.

# Exam / Interview Points

- **Waypoints** = pre-programmed GPS coordinates for autonomous flight
- Set home point: right-click map → **"Set Home Here"**
- Altitude mode: always use **Rel (Relative)** to home point
- **Survey (Grid)** = auto-generate waypoints for photogrammetry/mapping
- **Spline Waypoints** = smooth curved paths (avoids jerky turns)
- **"Write WPs"** button = uploads mission to flight controller
- **Prefetch** = save satellite imagery for offline field use
- Waypoint commands: **TAKEOFF, LAND, LOITER, DO_SET_ROI**
- Auxiliary channels (CH6/CH7) link transmitter knobs/switches to servo outputs
- **RCIN passthrough** = forward transmitter input directly to servo via FC

### Forensic Relevance

> Waypoint data extracted from the flight controller reveals the **planned mission route** — critical evidence showing premeditated intent. Comparing planned waypoints against actual flight logs can reveal deviations, aborted missions, or unauthorized destinations.
