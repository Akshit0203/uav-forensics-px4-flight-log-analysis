
# Telemetry Mechanics & System Health

---

## Critical Parameters to Check

### 1. Vibrations (IMU / Accelerometer)

The IMU contains gyroscopes and accelerometers that record flight vibrations. Look for excessive noise in the **Z-axis accelerometer logs**. High vibrations can desync motors or cause the drone to "toilet-bowl."

> [!IMPORTANT] Forensic Use — Proving Intentional vs Accidental Crash
> If a suspect claims *"the drone malfunctioned, I didn't crash it intentionally"*, vibration analysis can refute this. If the logs show vibration levels were perfectly normal and motors were functioning correctly right up to the moment of crash, the claim of system failure is negated. Conversely, if a motor was spinning at maximum RPM and vibrating excessively before falling, that points to genuine hardware malfunction.

### 2. Controller Tracking (Attitude)

Check if the **actual attitude** (roll, pitch, yaw) matches the **desired attitude** (pilot inputs). A lag between desired and actual values indicates poor PID tuning — not necessarily pilot intent.

### 3. Battery Voltage & Current

Look for **severe voltage sags under throttle**. A sudden voltage drop combined with a spike in current draw signals:
- A failing ESC
- A short circuit
- A cold or degraded battery

> [!TIP] Negating False Battery Failure Claims
> If a suspect blames a battery failure for the crash, but analysis shows the battery temperature, voltage, and remaining capacity were **stable up to the crash point**, you can legally negate their claim. Document these findings in the forensic report so the defense cannot exploit the excuse.

### 4. GPS & Satellites (HDOP)

Check for **low satellite counts** or **high HDOP values (>2.0)** if the drone experienced flyaways or poor position holding.

| GNSS System | Origin | Notes |
|-------------|--------|-------|
| GPS | USA | Standard |
| BeiDou | China | Growing coverage |
| GLONASS | Russia | Alternative constellation |
| NavIC | India | Currently has some limitations due to satellite outages |

- **Minimum 3 satellites** required for basic triangulation
- Drones typically track **6–8 satellites** for stable flight
- Applies to any single GNSS system being analyzed

## Telemetry & Black Box Logs (Machine-Recorded)

Telemetry logs are binary or text files recorded directly by the drone's flight controller or Ground Control Station (GCS). They track **sub-second physical movements and system health**.

Modern high-end transmitters act as complete ground control stations — you can mount a mobile phone to view live video feeds, and they record valuable logs extractable for forensic analysis.

### Log Types & Storage Locations

| Firmware / Platform | Log Format | Storage Location | Notes |
|--------------------|-----------|-----------------|-------|
| **DJI** | `.DAT` (encrypted) | Internal storage on drone | Proprietary encrypted format |
| **DJI** | `.TXT` | Mobile app folders: `/DJI/dji.go.v4/FlightRecord` or `/DJI/dji.pilot/FlightRecord` | App-recorded logs |
| **ArduPilot / PX4 / Pixhawk** | `.bin` (Dataflash) | SD card on the autopilot | Raw binary, stored locally |
| **PX4** | `.ulg` / `.ulog` | Flight controller | ULog format for system & sensor data |
| **GCS (Mission Planner / QGroundControl)** | `.tlog` | PC / tablet | Recorded when connected via telemetry link |

> [!NOTE] File Extension Logic
> Since flight controllers run on Linux-based or RTOS embedded systems, extensions are named logically: `.tlog` for telemetry logs, `.ulog`/`.ulg` for system & sensor logs, `.dat`/`.txt` for DJI logs.

### Analysis Pipeline

Raw logs → **decrypt/parse** → extract GPS paths, battery voltages, IMU data → **visualize in 3D** using tools like AirData UAV or AeroGCS.

### Why Flight Logs Matter Beyond Forensics

Flight logs are crucial for:
- **Regulatory compliance**
- **Warranty claims**
- **Accident investigations**
- **Tracking operational hours**

> [!EXAMPLE] Operational Hour Tracking — Real-World Use Case
> Commercial drone companies often rent out their drones. A client renting a drone might claim they flew only three hours a day for four days to spray their crops — but secretly use it to spray neighbors' fields as well. By tracking the operational hours logged in the flight controller, the company can prove exactly how long the drone was operated and charge accordingly.

## ULog Format

**ULog** is a self-describing binary file format used by PX4 to log system messages, sensor inputs, and internal states. The `.ulg` extension is standard for PX4 flight telemetry, CPU load, and sensor data.

### Parsing ULog Files

| Tool | Description |
|------|-------------|
| **pyulog** (CLI) | Convert `.ulg` files to CSV for analysis |
| **MATLAB ulogreader** | Process ULog files directly in MATLAB |

### Other Systems Named "ULog"

| System | Description |
|--------|-------------|
| **Amateur Radio (Ham)** | M0PZT uLog Software — simple logbook for quick QSO entry |
| **Embedded C Microcontrollers** | `rdpoor/ulog` (GitHub) — Log4j-style lightweight logging in pure C |
| **Mainframe (IBM z/OS)** | SDSF User Log — tracks MVS and JES commands during sessions |

> If the drone uses an amateur radio frequency, there are specific logging protocols for that as well.

## Extraction & Analysis Tools

Raw flight logs are heavily encrypted or binary — you need specialized software to **decrypt**, **convert to `.csv` or `.kml`**, and **display on a map**.

> [!NOTE] KML (Keyhole Markup Language)
> KML is the standard XML-based format used to display geographic data. GCS and flight controllers use KML files to share and map locations.

### DJI Log Extraction — Three Methods

#### Method 1: View in the App (Mobile or Smart Controller)

The quickest way to check flight path and basic telemetry:

1. Open the **DJI Fly**, **DJI GO 4**, or **DJI Pilot** app
2. Go to your **Profile** → tap **More**
3. Select any flight from the list to view the flight path on a map and check telemetry

#### Method 2: Transfer Files to a Computer

For detailed raw log files (e.g., insurance claims, DJI support submissions):

1. Connect your mobile device or remote controller to your computer via **USB cable**
2. **Android / DJI Smart Controller:**
   - Navigate to internal storage → `DJI` folder
   - Logs are in: `Android/data/dji.go.vX/files/FlightRecord`
3. **iOS (iPhone/iPad):**
   - Open **iTunes** (Windows / older macOS) or **Finder** (newer macOS)
   - Navigate to **File Sharing** tab → select your DJI app
   - Drag the `FlightRecord` folder to your computer

#### Method 3: Export Aircraft `.DAT` Logs (Black Box)

For deeper analysis (e.g., crash analysis), DJI support may request the aircraft's black box `.DAT` files rather than mobile telemetry:

1. Turn on the drone and connect it to your computer via **USB**
2. Open **DJI Assistant 2** desktop software
3. Select your drone → click **Log Export** → check the logs you need → save to PC

> [!WARNING] DJI Cloud Sync Discontinued
> DJI has discontinued cloud-syncing services. Flight records must now be accessed **locally** on your phone, tablet, or remote controller. Running a forensic lab requires investing in various drone models and GCS equipment, since you never know which model will appear in an investigation.
