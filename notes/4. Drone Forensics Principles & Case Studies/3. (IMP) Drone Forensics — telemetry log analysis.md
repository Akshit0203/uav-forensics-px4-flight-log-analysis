# (IMP) Drone Forensics — Telemetry Log Analysis

---

# 1. Anti-Drone Solutions

| Method | Description |
|---|---|
| **RF Fingerprinting** | Identify and catalog unique RF signatures of unauthorized drones |
| **Jamming** | Disrupt the drone's control signal or GPS |
| **Geofencing / No-Fly Zones** | Software-enforced boundaries preventing drone entry |
| **Tangle Drone** | Interceptor drone drops a **net** over the target drone |
| **Shotguns** | Physical projectile takedown |
| **Debris / Game Jerseys** | Physical obstruction screens |
| **Lasers** | Blind FPV cameras or damage optical sensors |

> **Context:** The vast majority of drone operators fly safely and legally. The illegal operators are a small minority — but significant enough to require **sound investigative techniques**. This module is aimed at investigators dealing with those operators.

---

# 2. Why Drone Forensics is Needed

## Illegal / Inappropriate Drone Activities

- **Drug delivery** across borders (e.g., Pakistan border — Rajasthan, Punjab, Jammu)
- **Drug and weapon delivery** to prisons
- **Invasion of privacy** (multiple incidents)
- **Flight above crowds** and in controlled airspace
- **Flight into operators and bystanders**

### Scale of the Problem

- **~20,000 DJI drones sold per month**
- Easy to assemble (DIY drones)
- Can swarm the skies in huge numbers

# 6. UAV Forensic Artifacts

## Physical Artifacts

| Category | Items |
|---|---|
| **Drone** | Flight controller, sensors, physical evidence (frame, markings, damage) |
| **Ground Station** | Data link, ground control station (GCS), radio controller |
| **Support & Post-Processing** | Maintenance system, image processing, billing, R&D |

## Digital Artifacts

| Category | Items |
|---|---|
| **Operating Systems** | Mobile OS, traditional OS, **embedded Linux** |
| **File Systems** | Variety (e.g., JFFS2, FAT32, UBIFS, F2FS) |
| **Storage** | Media storage, **EEPROMs**, removable SD cards |
| **Software** | Firmware, flight controller chip data logs |

## Other Artifacts

| Category | Items |
|---|---|
| **Documentation** | Mission planning files, maintenance logs, purchase records |
| **OSINT** | Social media activity |
| **Physical Trace** | Fingerprints on the drone/controller |

# 7. Drone Composition — What to Examine

| Component | Forensic Value |
|---|---|
| **Radio transceiver module** | Communication frequencies, binding data |
| **CPU + internal flash memory** | Firmware, cached data, logs |
| **Flight controller chip** | Data logging capabilities, PID settings, configs |
| **Sensors & compass** | Calibration data, orientation history |
| **Batteries** | Capacity → infer flight range |
| **Collision avoidance detectors** | Obstacle detection logs |
| **Removable SD card** | Blackbox logs, media, waypoints |
| **QR code, serial & model numbers** | Identify manufacturer, batch, owner |
| **Camera / carried payload** | Photos, videos, payload type |
| **Radio controller (often a smartphone)** | App data, paired device info, flight history |
| **FPV goggles / terminal** | Video feed recordings |
| **Wi-Fi range extender** (optional) | Extended control range evidence |
| **Laptop** (optional) | Waypoint configuration, Mission Planner logs |
| **Server** (ground or cloud) | Transferred and stored captured data |

---

# 8. Key Data to Extract from a Drone

| Data Type | Why It Matters |
|---|---|
| **Telemetry** | Real-time flight parameters — reconstruct flight events |
| **Waypoints** | Pre-programmed GPS coordinates — shows premeditated intent |
| **Multimedia files** | Photos/videos captured during flight — evidence of activity |
| **GPS coordinates** | Flight path, takeoff/landing locations, loiter points |
| **User details** | Operator identity, paired devices, accounts |
| **Firmware details** | Version, modifications, geofence bypasses |

# Exam / Interview Points

### Anti-Drone
- Methods: RF fingerprinting, jamming, geofencing, tangle drone (net), shotguns, lasers
- Most operators are legal — forensics targets the **illegal minority**

### Why DFL (Drone Forensic Lab) is Needed
- ~20,000 DJI drones sold/month + easy DIY assembly
- Illegal uses: drug/weapon smuggling, privacy invasion, no-fly zone violations

### Investigation Flow
- 5 phases: Mission Planning → Approval → Execution → Analysis → Delivery
- Three artifact categories: **Physical** (drone, GCS, radio) + **Digital** (OS, file systems, EEPROM, firmware) + **Other** (purchase records, social media, fingerprints)

### Key Extraction Targets
- **6 priority data types:** Telemetry, Waypoints, Multimedia, GPS, User details, Firmware
- Don't forget: QR codes, serial numbers, paired smartphone app data, cloud server data
- Embedded Linux + JFFS2 file system common on GCS hardware
- **EEPROMs** store persistent configuration data on the flight controller
